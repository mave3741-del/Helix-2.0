Contributing to Helix

Thank you for your interest in contributing to Helix!

Helix is an AI-driven trading research and analysis project. We welcome contributions that improve code quality, reliability, documentation, testing, security, and research workflows.

Ways to Contribute

* Fix bugs and improve reliability.
* Improve AI agent orchestration.
* Add or improve market data integrations.
* Improve backtesting and performance evaluation.
* Strengthen risk controls and testing.
* Improve documentation and developer experience.

Before You Start

1. Read the README.md to understand the project.
2. Check existing Issues to avoid duplicate work.
3. For significant changes, open an Issue or Discussion first.
4. Ask questions if the scope of a task is unclear.

Development Workflow

1. Fork the repository.
2. Create a separate branch for your changes.
3. Make focused, clearly explained changes.
4. Run the relevant tests available in the project.
5. Update documentation when necessary.
6. Submit a Pull Request describing your changes and test results.

Code Quality

* Follow the conventions used in the existing codebase.
* Keep changes focused and maintainable.
* Add tests when appropriate.
* Do not claim that a feature works unless it has been tested.
* Clearly identify experimental or incomplete features.

Security

* Never commit API keys, passwords, exchange credentials, tokens, or private data.
* Do not enable live trading or change trading permissions without explicit project-owner approval.
* Do not introduce unreviewed changes that could trigger real financial transactions.
* Report security vulnerabilities privately to the repository owner rather than publishing exploitable details.

Trading and Research Safety

Contributions involving strategies, market data, backtesting, and risk management should document assumptions and limitations.

Backtest results do not guarantee future performance. Do not represent unverified results as proven profitability.

Licensing

By submitting a contribution, you agree that your contribution will be distributed under the repository’s MIT License.

Please ensure you have the right to submit the code and that it complies with applicable third-party licenses.

Communication

Please be respectful, constructive, and transparent. Explain the problem, proposed solution, relevant tests, and any known limitations.

Thank you for helping improve Helix!
